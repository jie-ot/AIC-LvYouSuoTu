# 旅有所图

《旅有所图》是一款面向旅行场景的 AI 应用：用户上传旅行照片后，应用可以理解照片内容，沉淀旅行偏好和记忆，生成旅行人格报告与专属明信片，并据此规划下一段更贴合个人兴趣的行程。

项目由前端和后端组成：

- `前端/`：Next.js Web 界面，也包含 Capacitor Android 配置。
- `后端/`：FastAPI 服务，负责照片理解、旅行记忆、内容生成和行程规划。

## 快速开始

先阅读[后端使用说明](后端/README.md)完成环境变量、依赖和 API 服务配置，再阅读[前端使用说明](前端/README.md)启动用户界面。

本项目依赖火山方舟、DeepSeek 以及部分旅行信息工具的 API Key。真实密钥、数据库、上传文件和生成文件均属于本地运行数据，不应提交到 GitHub；配置时请复制 `.env.example` 和 `.env.local.example`，不要修改模板来保存密钥。

## 技术栈

Next.js、React、TypeScript、Capacitor、FastAPI、SQLAlchemy、Alembic 和 SQLite。

## 项目状态

这是面向比赛演示的单用户应用原型，不包含生产级身份系统、私有对象存储和分布式任务队列。模型生成和旅行信息查询依赖外部服务，实际能力取决于本地配置的 API Key、网络和服务状态。
